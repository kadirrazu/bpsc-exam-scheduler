# v1.7.7 — Compact exam details and emphasized values

Based on the v1.7.6 detail-layout patch following project-reference-27-10-2026-11-54-PM.zip. Footer version: v1.7.7. Root README remains unchanged.

- Removes the Field/Value header row and makes detail values bold. The existing summary remains above the details.
- Exam Type, Unit and Post Code share one row of three cells; mobile stacks them.
- Post Name & Grade shows Post Name (Grade: X). A missing grade omits the full suffix, including parentheses. Post Code, Post Name and Ministry/Organization use distinct purple/blue/green colors; the grade suffix is amber.
- Advertisement Number & Year is one row. Either missing component is handled without empty parentheses; both missing show a dash.
- Time uses the dashboard's existing start - end formatter, or Start only for Viva. No separate Start/End rows remain.
- Vacant Posts appears immediately above Candidates. Viva board structure, conditional Boards/Centers, status colors, multiline notes and final Last Updated row are preserved.
- Existing Viewer access, edit/delete controls, stored values, API and audit behavior are unchanged.

## Apply

Replace included files at the project root after v1.7.6, then:

```bash
php artisan optimize:clear
```

Hard refresh with Ctrl+F5. Compiled CSS is included. No migration, seeding, Composer install or npm build is required.
