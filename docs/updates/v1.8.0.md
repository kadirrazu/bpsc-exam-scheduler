# v1.8.0 — Automatic completion of past Scheduled exams

Based on project-reference-27-10-2026-11-54-PM.zip (v1.7.5). Footer version: v1.8.0. Root README remains unchanged.

## Behavior

The Laravel scheduler checks once daily at 20:00 Asia/Dhaka. Non-deleted Scheduled exams dated before today in Asia/Dhaka become Completed, with a version increment and explicit System audit. Today's exams stay unchanged regardless of End Time; other statuses stay unchanged. All exam types are supported. Backlog is caught on the next successful daily run after downtime. Audit writes and each row transition share a transaction; a failed audit rolls back that row. Repeated runs are idempotent and manual stale edits still receive 409.

## Apply

Back up the project/database, then replace included files at the project root. Preserve .env, APP_KEY and the database. Do not replace your real .env with .env.example.

```bash
php artisan optimize:clear
php artisan scheduler:complete-past-exams --dry-run
php artisan schedule:list
php artisan test
```

No migration, seeding, Composer installation or npm build is required. UI/build assets are unchanged. The new .env.example flag is documentation only; automatic completion defaults on even without adding the flag to your existing .env.

## Activate the host scheduler

For local testing, keep a terminal open with:

```bash
php artisan schedule:work
```

For unattended Windows operation, create one daily 8:00 PM task running `php artisan scheduler:complete-past-exams --scheduled` on a PC configured to Dhaka time. Existing Laravel master schedulers can use the registered daily event instead. Full WAMP executable/argument paths, cron example, audit verification and enable/disable instructions are in ../AUTOMATIC-COMPLETION.md. A working existing Laravel host scheduler will begin this task on its next daily 20:00 Asia/Dhaka due time; the patch does not create an operating-system task itself.

To complete eligible records immediately:

```bash
php artisan scheduler:complete-past-exams
```
