# v1.6.0 — Date-wise schedules, Viva board structure and vacancies

Based on v1.5.1. Footer version: v1.6.0. Root README remains unchanged.

## Changes

- Exam Type is a separate column immediately after Date. Start/End share a Time column with a spaced hyphen; Viva shows Start only. Applied to web tables, print, PDF and XLSX.
- Exam rows remains the default. Date-wise rows merges each date cell across its exam subrows. Dashboard/list switching retains filters; exports use the selected display too. Flat pagination uses 25 exams; grouped pagination uses 25 distinct dates, keeping all matching exams on a date together.
- Optional Number of Vacant Posts follows Post Grade in the entry form. Bengali/English numeric input is accepted; zero and null stay distinct. Visible in schedules/details/reports and audit snapshots.
- Viva hides/disables End Time and adds optional repeatable Board Structure. Example: 15 × 3 plus 12 × 4 fills 7 Boards and 93 Candidates. Both totals can be manually edited. Opening an existing entry preserves manual totals; changing a complete valid structure recalculates them. Removing all structure rows leaves the totals available for manual entry.
- Web/API validation, storage and audits cover the new fields. API creation now returns the persisted version required for edits. See ../API.md for payloads, grouped response shape and revised XLSX columns.
- PDF text uses Bengali and Latin font runs so dashes/multiplication symbols render correctly while retaining bold headings and credits.

## Apply

Back up the database and project first. Apply after v1.5.1, replacing included files at the project root. Keep .env, APP_KEY and existing database unchanged. Compiled frontend JavaScript is included; no Composer install or npm build is needed.

```bash
php artisan optimize:clear
php artisan migrate
php artisan test
```

Hard refresh with Ctrl+F5. This migration only adds two nullable columns; it does not rewrite previous exams or delete legacy Viva end times. Reports hide those old Viva end times; saving a Viva record clears its End Time. New structure/vacancy fields default to null for existing records. Do not run migrate:fresh on a live database.

Grouped XLSX merges only Date cells and omits AutoFilter to avoid filtering merged groups. Numeric counts/grades/vacancies remain numeric cells. Grouped API pagination changes only with explicit display=grouped. PDF may move a large merged date group to a fresh page, leaving whitespace to preserve the group.
