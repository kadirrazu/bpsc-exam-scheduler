# v1.7.1 — Calendar layout, colors and navigation

Based on v1.7.0. Footer version: v1.7.1. Root README remains unchanged.

- Calendar moves to the top navigation immediately after Dashboard, with its own active state. It is removed from Exam Management.
- Fixes the narrow day-link layout: Tabler's .calendar-date enforced max-width 14.28% on each nested link. Isolated bpsc-calendar-* selectors now fill each day cell without inheriting those rules.
- Dates with matching exams have a pale blue background. Dates, exam counts and type information have distinct blue/orange/green colors. Desktop previews up to two types; tooltip retains the full breakdown. Mobile shows compact date/count/type totals and opens full details on tap.
- Tooltip gains a colored background, distinct text colors, smooth fade/slide transitions and keyboard-focus support. Reduced-motion preferences disable transitions. Existing filters, day details, permissions, API and audits are unchanged.

## Apply

Replace included files at the project root after v1.7.0, then:

```bash
php artisan optimize:clear
```

Hard refresh with Ctrl+F5 so the new compiled CSS is loaded. No migration, seeding, Composer install or npm build is required.

9 existing catalog/calendar tests / 163 assertions passed on PHP 8.3 and SQLite/Linux; Blade templates compiled and production assets rebuilt. The conflicting vendor rule was inspected directly. Direct browser rendering and Windows/WAMP execution were unavailable.
