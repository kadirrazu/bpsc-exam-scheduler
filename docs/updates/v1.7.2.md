# v1.7.2 — Calendar visual polish and weekend columns

Based on v1.7.1. Footer version: v1.7.2. Root README remains unchanged.

- Refined month toolbar, softer surfaces, rounded cells and a small visual legend.
- Dates are larger and centered. Exam-free dates use subdued gray and a small No exams label instead of prominent zero counts.
- Exam dates show Exam count: with a contrasting numeric badge. A separator precedes the complete type-name/count breakdown in smaller text; long names wrap and no type rows are truncated.
- Friday and Saturday headers/cells have matching weekend backgrounds and red-toned date numbers. Exams on weekends still count and remain selectable.
- Mobile preserves readable seven-column cells with horizontal scrolling confined to the calendar. Full details remain available when selecting a date.
- Animated tooltip summaries are positioned outside the scroll container to prevent clipping. Keyboard focus remains supported; Escape, scroll and resize dismiss the popup. Reduced-motion settings disable animations.
- Filters, API, day tables, permissions and audit behavior are unchanged.

## Apply

Replace included files at the project root after v1.7.1, then:

```bash
php artisan optimize:clear
```

Hard refresh with Ctrl+F5 to load the updated compiled CSS and JavaScript. No migration, seeding, Composer install or npm build is required.
