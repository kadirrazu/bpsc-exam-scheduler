# v1.7.3 — Calendar contrast and week order

Based on v1.7.2. Footer version: v1.7.3. Root README remains unchanged.

- Adds No exam day to the legend beside Exam day and Weekly holiday.
- Empty dates use gray-family backgrounds; empty weekend dates use a slightly warm gray. Existing backgrounds for dates with exams remain unchanged.
- Calendar headers and grid now run Sunday through Saturday, placing Friday/Saturday together in the last two columns.
- Stronger dark blue count labels, dark amber totals and dark green type text/count badges improve readability against exam-day backgrounds.
- Today has a prominent 3px blue border and pale outer ring; hover/focus does not weaken the border.
- Existing calendar filters, totals, day details, tooltips, permissions and API records are unchanged.

## Apply

Replace included files at the project root after v1.7.2, then:

```bash
php artisan optimize:clear
```

Hard refresh with Ctrl+F5. Compiled CSS is included. No migration, seeding, Composer install or npm build is required.
