# v1.6.2 — Compact schedule tables and report footers

Based on v1.6.1. Footer version: v1.6.2. Root README remains unchanged.

- Unit and Exam Type share one column, on separate lines, in flat/date-wise schedules, dashboard, print, PDF and XLSX. Unit values and exam type labels remain English in both languages.
- Boards shows one structure per line, then the saved Total Boards on a separate bold line. Manual overrides remain authoritative; reports do not recalculate totals. No duplicate board structure beneath Post Name. Viva without structure retains its board count; non-Viva shows a dash in web/PDF tables.
- PDF table headers repeat on every page; page numbers remain in the bottom footer. Credits appear on every PDF page, in literal English, 7pt and true 65% opacity, with only IT Section, BPSC bold. The printed timestamp remains centered in the footer. Web-print credit uses a fixed footer with CSS opacity 0.65.
- XLSX now has 16 columns (A..P); merged Date/per-date serial behavior is retained. Board structures and combined Unit/type use cell line breaks. Headers repeat on workbook print pages. See ../API.md for the revised column map. Raw API schedule fields, permissions and database records are unchanged.

## Apply

Apply after v1.6.1. Replace included files at the project root, then:

```bash
php artisan optimize:clear
php artisan test
```

Refresh the page. No migration, Composer installation or npm build is required. Font/build assets are unchanged.
