# v1.6.1 — Form rows, per-date serials and AM/PM

Based on v1.6.0. Footer version: v1.6.1. Root README remains unchanged.

- Desktop form row 1: Exam Type, Unit, Post Code. Row 2: Post Name, Post Grade, Number of Vacant Posts. Mobile preserves this reading order in stacked fields.
- Viva Board Structure appears immediately above Candidates and Boards. Other lower fields retain their layout; structure calculations/manual overrides are unchanged. Add and Edit share this form.
- Date-wise tables now show Date first, then the serial for that date, starting at 1 on every new date. Applied to list/dashboard, print, PDF and XLSX. Flat tables retain their existing continuous serial and column order.
- Grouped XLSX merges Date in column A; per-date Serial is B. Flat XLSX retains Serial A and Date B. Other columns and raw API payloads are unchanged.
- AM/PM remains English in both languages, including report/footer timestamps. Bengali digits and date labels still localize at display time.

## Apply

Apply after v1.6.0. Replace included files at the project root, then:

```bash
php artisan optimize:clear
php artisan test
```

Refresh the page. This patch adds no migration and changes no JavaScript/CSS assets; no npm build or Composer install is needed. The v1.6.0 migration must already be applied.
